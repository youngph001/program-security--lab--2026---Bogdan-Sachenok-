# Scope — SecureScan (Program Security Lab 2026)
## Призначення системи
SecureScan — це система для автоматизованого аналізу вихідного коду на наявність вразливостей безпеки. Система приймає код на перевірку, аналізує його за заданими правилами та формує звіт із виявленими проблемами.
## Що входить у межі проєкту (In Scope)
- Прийом вихідного коду (завантаження архіву або посилання на Git-репозиторій).
- Статичний аналіз коду (SAST) на пошук типових вразливостей (SQL-ін'єкції, XSS, витік чутливих даних).
- Класифікація знайдених вразливостей за рівнем критичності (Low, Medium, High, Critical).
- Формування звіту про сканування у форматах JSON та HTML.
- Збереження історії сканувань для конкретного проєкту.
## Що НЕ входить у межі проєкту (Out of Scope)
- Автоматичне виправлення знайденого коду (система лише вказує на проблему).
- Динамічний аналіз (DAST) або запуск коду в пісочниці.
- Управління користувачами та ролями (авторизація винесена в окрему систему).
- Написання власних правил безпеки (використовуються готові бібліотеки правил).
## Зацікавлені сторони (Stakeholders)
- **Розробники** — хочуть швидко перевірити свій код перед комітом.
- **Спеціалісти з безпеки (Security Engineers)** — потребують детальних звітів про знайдені вразливості.
- **Технічні лідери / Менеджери** — хочуть бачити загальний стан безпеки проєкту.
