# Architecture — SecureScan (Program Security Lab 2026)
> Архітектурний опис складено згідно з ISO/IEC/IEEE 42010:2022.
> Документ описує структуру системи, її компоненти та взаємозв'язки.
## 1. Зацікавлені сторони та їхні потреби
| Сторона | Потреба |
|---|---|
| Розробник | Зрозуміти, у який шар додавати нову логіку; дотриматись політики проєкту |
| Архітектор | Перевірити межі шарів та напрямок залежностей |
| Security Engineer | Розуміти, як формується звіт та де зберігаються результати |
| DevOps | Знати, як збирається та розгортається система, які зовнішні залежності |
## 2. Архітектурні представлення
### 2.1. Загальна структура (Layered View)
Система побудована за принципом багатошарової архітектури з жорсткими межами між шарами:

```text
┌───────────────────────────────────────────────────────┐
│  EntryPoint / Presentation (HTTP, CLI)                │
│  - Контролери, консольні команди                      │
│  - Тільки прийом вводу та формування відповіді        │
└───────────────────────┬───────────────────────────────┘
                        │
                        ▼
┌───────────────────────────────────────────────────────┐
│  Application (Use Cases, CQRS)                        │
│  - Commands: StartScanAC, CancelScanAC                │
│  - Queries: GetScanAQ, ListScansAQ                    │
│  - Оркестрація Domain + Infrastructure                │
└───────────────────────┬───────────────────────────────┘
                        │
                        ▼
┌───────────────────────────────────────────────────────┐
│  Domain (Business Logic, DDD)                         │
│  - BC: Scan, Report, Rule                             │
│  - Entities, Value Objects, Policies, Services        │
│  - OutsourceContract — інтерфейси назовні             │
└───────────────────────▲───────────────────────────────┘
                        │ (реалізація контрактів)
┌───────────────────────┴───────────────────────────────┐
│  Infrastructure                                       │
│  - Transport (HTTP-клієнт для Git)                    │
│  - Persistence (БД для метаданих сканувань)           │
│  - Parser (AST-парсер PHP/JS)                         │
└───────────────────────────────────────────────────────┘
