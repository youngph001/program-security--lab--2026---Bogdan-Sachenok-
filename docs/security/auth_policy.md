# Політика автентифікації (SecureScan)

## 1. Ідентифікація
- **Ідентифікатор:** Email або Логін.
- **Сценарії:** Реєстрація, вхід, відновлення пароля.

## 2. Методи автентифікації
- **Обов'язковий:** Пароль (фактор знання).
- **Опційний:** Одноразовий код (TOTP) для адміністраторів.

## 3. Зберігання та сесії
- **Паролі:** Зберігаються виключно у вигляді хешу (PBKDF2-HMAC-SHA256 з сіллю).
- **Перевірка:** Порівняння хешу введеного пароля з еталонним.
- **Сесія:** Використання JWT-токенів. Вихід із системи анулює токен.
