# Tech Notes — Rule

## Відомі проблеми
- Каталог правил поки що вбудований, без можливості оновлення без релізу.

## Техборг
- Додати валідацію regex-патернів при реєстрації правила.
- Реалізувати міграцію правил між версіями схеми.
- Додати тести на коректність AST-патернів для PHP.

## Неочевидні рішення
- Правило ніколи не видаляється фізично — тільки переходить у статус `DEPRECATED`. Це потрібно для історичної цілісності звітів: старі звіти посилаються на старі правила.
- Код правила (`RuleCodeVO`) має фіксований формат `SS-<TYPE>-<NUM>`, що дозволяє швидко зрозуміти тип правила без запиту до БД.

## Edge cases
- Спроба активувати застаріле правило → `RuleCannotBeReactivatedException`.
- Реєстрація правила з дублікатом `code` → `RuleCodeAlreadyExistsException`.
- Правило з невалідним regex → `PatternInvalidException`.
