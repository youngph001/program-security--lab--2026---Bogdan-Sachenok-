# Tech Notes — SharedKernel

## Відомі проблеми
- Trait `TEventQueue` використовує `spl_object_id` для дедуплікації — потребує перевірки на edge cases при серіалізації.

## Техборг
- Додати більше спільних VO (наприклад, `EmailVO`, `MoneyVO`) у міру потреби.
- Розглянути можливість винести `TEventQueue` в окремий пакет, якщо знадобиться в інших проєктах.

## Неочевидні рішення
- `ASecureScanException` реалізує `\Exception` напряму, а не через `\RuntimeException` чи `\LogicException`, щоб не нав'язувати семантику всім нащадкам.
- `AEntityUuidVO` валідує UUID у конструкторі — це єдине місце перевірки, нащадки не повторюють валідацію.

## Edge cases
- Додавання в SharedKernel елемента, який використовується лише в одному BC → має бути відхилено на рев'ю (але не блокується технічно).
- Зміна базової абстракції (`AValueObject`, `AEntity`) → потенційно ламає всі BC; потребує окремого релізу з повним прогоном тестів.
