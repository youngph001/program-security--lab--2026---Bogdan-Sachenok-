# Tech Notes — Scan

## Відомі проблеми
- Поки що відсутня обробка таймаутів при Git-клонуванні великих репозиторіїв.

## Техборг
- Додати тести для `CancelScanDPolicy` на всі статуси.
- Реалізувати retry-логіку для `RunScanService` при тимчасових помилках парсера.

## Неочевидні рішення
- Вразливості зберігаються всередині агрегату `Scan` як internal Entity, а не як окремий Aggregate Root: вони не мають власного життєвого циклу поза скануванням.
- Сканування виконується асинхронно, щоб HTTP-запит не блокувався на довгий час.

## Edge cases
- Порожній архів (0 файлів) → сканування завершується зі статусом `COMPLETED` і 0 вразливостей.
- Git-URL недоступний → сканування переходить у `FAILED` з відповідним reason.
