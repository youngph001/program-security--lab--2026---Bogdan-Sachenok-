# Tech Notes — Report

## Відомі проблеми
- HTML-експорт використовує простий шаблон без підсвічування синтаксису коду.

## Техборг
- Додати підтримку PDF-формату звіту.
- Реалізувати пагінацію у `ListReportsAQ` при великій кількості звітів.

## Неочевидні рішення
- Звіт створюється лише для сканування у статусі `COMPLETED`. Для `FAILED` та `CANCELLED` звіт не створюється, бо немає що звітувати.
- `payload` зберігається як JSON у БД, а не як окремі рядки, щоб не дублювати структуру вразливостей.

## Edge cases
- Сканування без жодної вразливості → звіт з порожнім списком, але зі статистикою (усі нулі).
- Спроба експортувати видалений звіт → `ReportNotFoundException`.
- Одночасний експорт одного звіту в JSON і HTML → два незалежні кеш-ключі.
